# העברת המערכת לשרת Windows 64-bit

החבילה כוללת את קובצי המערכת המעודכנים, כל הממשק, Node.js 24.15.0, כל התלויות, הגופן העברי, בדיקות, סקריפטים, תהליכי n8n ופרוצדורות Priority. אין צורך להתקין Node.js או להריץ npm בשרת.

## עדכון שרת קיים

1. עצרו את שרת החשבוניות הקיים וסגרו את חלון ההפעלה שלו.
2. גבו את כל התיקייה הקיימת, ובעיקר את קובץ ההגדרות `.env` ואת כל תיקיית `data`.
3. חלצו את ה-ZIP לתיקייה חדשה בשרת. אל תפעילו מתוך ה-ZIP ואל תחלצו את הגרסה החדשה מעל תיקיית השרת הפעיל.
4. העתיקו אל התיקייה החדשה את `.env` ואת כל תיקיית `data` מהשרת הקיים. שמרו את הגדרות השרת גם אם החבילה כוללת הגדרות מהמחשב שבו נארזה.
5. הפעילו `start-server.bat` והשאירו את החלון פתוח.
6. פתחו `http://localhost:18473/?agent=90` בשרת, או החליפו localhost בכתובת השרת בטלפון/טאבלט. כל סוכן משתמש בקישור עם מספר הסוכן שלו.
7. ודאו חיבור לחברת Priority הנכונה ונסו לבחור לקוח ומוצרים לפני הפקה.

תיקיית data של השרת כוללת מקורות ורישומי יצירה/מייל/חתימה שמונעים כפילויות. היא אינה כלולה בחבילת העדכון ואסור לאבד אותה או להחליף אותה בנתוני מחשב אחר. השאירו את התיקייה הישנה לגיבוי וחזרה לגרסה קודמת. אין צורך לשנות את כללי הרשת הקיימים עבור אותו פורט.

## התקנה חדשה

חלצו לתיקייה חדשה, בדקו את הגדרות .env והפעילו start-server.bat. חבילה מוגדרת כוללת .env; חבילה ללא הגדרות כוללת .env.example כתבנית. השרת יוצר תיקיית data בעת הצורך. אל תפעילו במקביל שני שרתים שמפיקים או שולחים את אותן חשבוניות עם מאגרי data נפרדים.

## ההתנהגות המעודכנת

- ממשק טלפון וטאבלט עם מספר הסוכן בכותרת.
- בחירת זהב, יהלומים טבעיים או יהלומי מעבדה.
- הנחה גורפת מסונכרנת מעל ומתחת למוצרים; כל שורה חדשה יורשת אותה. החלפת סוג חשבונית מאפסת את ההנחות לאפס.
- שורות ריקות ללא קלט מנוקות לפני מעבר לבדיקה.
- המקור נשמר בפריוריטי; מייל נשלח לפי הבחירה. אין הורדת PDF אוטומטית. בסיום ניתן ללחוץ על ״הורדת מקור״.
- חתימת הלקוח נשמרת כהעתק חתום בנספחי אותה חשבונית.

## קבצים ואימות

רשימת קבצים וחתימות SHA256: PACKAGE-SHA256.txt. פרטי הבנייה: build-info.json. קובצי המקור הם תמונת מצב של תיקיית העבודה, כולל השינויים האחרונים שטרם בוצע להם commit. לוגים, מסמכים אמיתיים, תמונות ביקורת, תיקיות עבודה של סוכנים וחבילות ZIP ישנות אינם חלק מההתקנה.

חבילה עם .env מכילה סיסמאות ופרטי גישה. העבירו אותה באופן פרטי והימנעו מהעלאה למאגר קוד או לקישור ציבורי.
