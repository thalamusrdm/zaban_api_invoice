# Automatic customer number explanation

When `WTAXNUMEXPL` is blank, the customer screen previews the explanation inferred from `WTAXNUM`. The normal transition to products saves it through the existing Priority customer SDK workflow, together with email, phone and electronic-document settings. GET requests remain read-only. The server uses the current Priority row, not a classification supplied by the browser, and reads the saved record back before reporting success.

The shared classifier is `public/customer-tax.js`. It requires nine digits and a valid Israeli check digit. Domestic company prefixes 51/52 map to **2 – company**; individual identifiers starting with 0–3 map to **1 – self-employed / identity number**. Existing values, including **3 – registered VAT dealer**, are preserved. Invalid numbers, unknown ranges, associations, partnerships and foreign identifiers receive no automatic classification. A missing identification/VAT number is not invented or copied to another field.

An individual's number does not establish whether that person is a registered or exempt VAT dealer. Therefore this feature never infers code 3 solely from an identity number, a populated VAT number or a customer name. Official VAT status requires separate evidence. Sources: [Israeli Tax Authority identification-number description via OECD](https://www.oecd.org/content/dam/oecd/en/topics/policy-issue-focus/aeoi/israel-tin.pdf), [Tax Authority VAT registration inquiry](https://www.gov.il/he/service/vat-apply-online). These rules classify the identifier; they do not guarantee allocation approval or establish legal limited-liability status.

Verified on 2026-11-16: the configured Priority `CUSTOMERS.WTAXNUMEXPL` column exists, is text (one character), is writable, and has title `הסבר על מספר התיק`. No real customer was changed during development. Automated tests cover inference, existing values, read-only loading, combined contact saves, missing mandatory fields, rejected writes, persisted-value verification and customer-screen updates.
