איך בוחנים את המסלול?

אפשר לבחור מסך מהרשימה או להתחיל בכניסה ולהתקדם דרך הכפתורים. מזינים פרטי דמה, עורכים מוצרים, בוחרים משלוח ועוברים לחתימה. כל תצוגה שומרת את ההתקדמות שלה עד לרענון.

החלטות שעדיין פתוחות

  • המייל נשאר חובה והמשלוח מסומן מראש, כמו במערכת הנוכחית.
  • השלמה מאוחרת, בדיקת מצב וחיפוש מסמכים מוצגים כהצעה; הם דורשים מימוש והרשאות.
  • אין חיבור לפריוריטי, שמירה חיצונית, יצירת מסמך או שליחת מייל.
