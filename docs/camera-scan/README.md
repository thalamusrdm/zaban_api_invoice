# סריקת מוצרים במצלמה

כפתור סריקה ליד הוספת מוצר מפעיל את @zxing/browser 0.2.1 (עותק מקומי ב-public/vendor, ללא CDN). הספרייה מפענחת ברקוד ו-QR במכשיר; תמונת המצלמה אינה נשלחת לשרת. רק הקוד המפוענח מועבר לחיפוש המוצר הקיים.

- סריקה חיה בטלפון דורשת HTTPS והרשאת מצלמה. localhost מתאים לפיתוח; כתובת IP מקומית ב-HTTP אינה מאפשרת סריקה חיה.
- אפשר לצלם ברקוד או לבחור תמונה גם כשהסריקה החיה אינה זמינה.
- המצלמה האחורית מועדפת. זיהוי ראשון סוגר את הסורק, ממלא מק״ט ומחיר דרך הבדיקה הקיימת בפריוריטי ומעביר למק״ט הבא. קוד לא מוכר או מסוג חשבונית אחר אינו מאושר אוטומטית.
- ההנחה הגורפת עוברת גם למוצר שנסרק. שורה עם כמות, מחיר או הנחה ידנית אינה נדרסת.
- סגירה, מעבר שלב, מעבר לרקע ועזיבת העמוד מפסיקים את המצלמה. תוצאות מאוחרות ובקשות הרשאה שבוטלו אינן מוסיפות מוצרים.

## אימות

בדיקות אוטומטיות מכסות מיקוד ישיר למק״ט, חיבור לחיפוש המוצר, הרשאות, עצירת מצלמה, זיהוי כפול, צילום וביטול בזמן פענוח. בדיקת המפענח משתמשת בעותק UMD שנשלח למשתמש ובתמונות QR ו-Code128 אמיתיות עבור קוד הדגמה 400001.

בדפדפן הפנימי נבדק פענוח שתי התמונות למוצר L001 בסביבת הדגמה מבודדת, עם מחיר 300 USD והנחה 83%, ומיקוד למק״ט הבא. נבדקה תצוגה ברוחב 390 ו-834 פיקסלים ללא גלילה אופקית. גישת מצלמה חסומה בכוונה בסביבת ההדגמה בלבד; סריקה חיה מול מצלמה פיזית בטלפון עדיין דורשת בדיקת מכשיר.

תמונות המסך והברקודים בתיקייה מכילים נתוני הדגמה בלבד. סקריפט יצירת הברקודים: docs/ux-audit-2026-11-16/create-camera-fixtures.cjs.

לא נוצרה חבילת שרת בעקבות שינוי זה.

## תיקון זיהוי בפריים חי

הופעל TRY_HARDER במפענח המשותף לצילום ולווידאו, והרזולוציה המועדפת עלתה ל-1920×1080. תצוגת הווידאו מציגה את כל הפריים ללא חיתוך. לאחר כ-25 ניסיונות ללא זיהוי מוצגת הנחיית מיקום; שגיאת פענוח בלתי צפויה מפסיקה ומשחררת מצלמה ומציגה אפשרות ניסיון נוסף, במקום להתעלם משגיאה שעצרה את הלולאה.

נוספה בדיקה מול עותק ZXing שנשלח לדפדפן: Code128 חד בחלק העליון של פריים בגובה 900 נכשל בהגדרות הקודמות ומפוענח בהגדרות החדשות. הבדיקה אינה מוכיחה שזהו הגורם היחיד לתקלה שדווחה מהאייפון; יש לאמת שוב מול הברקוד הפיזי. כלל 167 הבדיקות עברו. קובצי הסקריפט קיבלו פרמטר גרסה כדי לעדכן את עותק הדפדפן ברענון.
